Hardcoded or Resource?

Switch the app language. Resource references update; hardcoded text does not.

RESOURCE FILESCOMPARE
layout.xmlandroid:text="@string/find_beer"
values/strings.xml<string name="find_beer">Find Beer!</string>
values-zh/strings.xml<string name="find_beer">查找啤酒</string>
The layout points to a name. Android selects the value for the current language.
